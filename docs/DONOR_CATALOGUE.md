**Usage gate for every proposed adaptation:**

1. Pin the donor's exact commit and inspect the real relevant files.
2. Record original author, SPDX licence, NOTICE, external dependencies and any embedded third-party asset rights.
3. Identify **behaviour and reusable boundaries** before choosing to copy code.
4. Prefer independent implementations where licences or game-specific coupling are uncertain.
5. Preserve required notices, source evidence, numerical limitations and attribution in the eventual PR.
6. Test the resulting game or module independently. Never inherit a donor's claims or proof coverage automatically.

Future source additions are allowed and additive; this document preserves the 26 original donor references as a stable baseline.
