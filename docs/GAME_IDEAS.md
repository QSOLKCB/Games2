# Games2 — preserved game idea catalogue

This is a **catalogue of concepts, not a list of shipped or implemented games**. Commercial titles are used as references for genre/mechanics. Every eventual Games2 title must use original QSOL-IMC design, assets, names and code with rights reviewed.

**Source:** the [pre-foundation README preserved verbatim](ORIGINAL_README_2026-11-16.md). That source remains available unchanged. Additional earlier proposals are identified separately rather than silently treated as entries in that source.

## Original Games2 README concepts

### Immersive and action FPS
- System Shock-inspired immersive FPS with more accessible controls.
- Syndicate (2012)-style cyberpunk FPS.

### Arcade run-and-gun, brawlers and shooters
- NARC.
- Ninja Warriors.
- Shadow Warriors.
- The Punisher.
- Lethal Enforcers.
- Snow Brothers / Bubble Bobble.
- Shadow Dancer.
- Golden Axe.
- Ninja Combat.
- Cabal.

### Fighting games and retro formats
- Mortal Kombat-style fighting.
- Street Fighter II-style fighting (original spelling in README: “Steet Fighter 2”).
- Pinball.

### Survival and sandbox
- Minecraft-style creative/sandbox building.
- Survival game.

### Real-time strategy and defence
- StarCraft-style RTS.
- Command & Conquer-style RTS.
- StarCraft UMS-inspired scenario rules, including WWII and paintball modes.
- Mech RTS and base-building.
- Tower defence.

### Investigation and exploration
- Futuristic Carmen Sandiego-style investigation.

### Space
- Subspace: Continuum-style top-down multiplayer-space combat concepts (first local/offline scope remains a separate design decision).
- Star Wars: The Arcade Game-style rail shooter.
- Star Trek: Bridge Commander-style bridge/ship simulation.
- Wing Commander IV / Prophecy-style cinematic space combat, without locking game simulation to 24 fps.

### Platforming, racing and mechs
- Super Mario Bros. 3-style platforming.
- Mario Kart-style arcade racing.
- MechWarrior-style mech simulation.

## Curation policy

- Do not delete earlier entries to favour a new idea. Amend status and add explanatory notes.
- Distinguish proposed, in development, playable, reviewed/released, and archived.
- A genre reference is **not permission to copy art, code, music, level layouts or franchise branding**.
- Each selected game receives its own directory and game-specific README, AGENTS and ROADMAP.
- A future prioritisation or upstream-engine review cannot change this source history silently.
