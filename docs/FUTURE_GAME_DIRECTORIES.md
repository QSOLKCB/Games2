## Selected release sequence

1. Complete Strike Pixel SP-002 graphics, gameplay and presentation polish;
   verify source and actual packaged browser play; pass owner release review.
2. Implement the original NARC-inspired **Circuit Vice** as NC-001 (one game PR).
3. Polish Circuit Vice as NC-002 (separate PR), then owner release review.
4. Choose the next title from these original concepts based on gameplay scope,
   genre diversity and tested engine reuse (initial candidates:
   `cyber-ninja/`, `immersive-fps/`, `pinball/`, `star-command-rts/`).
5. Assess proven reusable systems with VANILLAJS after three finished Games2
   titles, or earlier with specific owner authorization.

The cabinet registry
remains an explicit publication allowlist. New directories are neither auto-built
nor published. See [the monorepo roadmap](../ROADMAP.md).
